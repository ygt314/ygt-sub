# 学科HTML

一个专注于学科教学的 HTML 开源项目，提供可直接在浏览器中运行的学科工具与学习资源。

## 简介

本项目收录了涵盖多个学科的交互式网页和工具，包括数学计算器、化学元素查询、函数图像绘制等，旨在为编程与计算机科学教学提供可复用的教育内容模板。

### 主要功能页面

| 页面 | 说明 |
|------|------|
| [YGTWEB.html](YGTWEB.html) | 主网页入口 |
| [Math.html](Math.html) | 数学学科页面 |
| [Chemistry.html](Chemistry.html) | 化学学科页面 |
| [English.html](English.html) | 英语学科页面 |
| [History.html](History.html) | 历史学科页面 |
| [chinese.html](chinese.html) | 语文学科页面 |
| [M_and_C.html](M_and_C.html) | 数学与化学综合页面 |
| [funcimg.html](funcimg.html) | 函数图像绘制工具 |
| [mycal.html](mycal.html) | 计算器工具 |
| [mymathf.html](mymathf.html) | 内嵌 Desmos API 的数学工具 |

### 核心脚本资源

| 文件 | 说明 |

## 使用方式

直接在浏览器中打开 HTML 文件即可使用，无需额外配置或服务器环境。适合课堂教学、自学辅助及编程教学演示。
