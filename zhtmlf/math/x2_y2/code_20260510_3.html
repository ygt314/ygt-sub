💡 开始前提醒

独立性检验是用来判断两个分类变量是否有关联，而不是判断因果关系！

📚 公式速查

卡方统计量公式：

$$\chi^2 = \sum \frac{(n_{ij} - E_{ij})^2}{E_{ij}}$$

其中 \(E_{ij} = \frac{n_{i.} \times n_{.j}}{n}\)

自由度：

$$df = (r-1)(c-1)$$

r为行数，c为列数

常用临界值表：

α 0.05 0.025 0.01 0.005
χ²₀ 3.841 5.024 6.635 7.879

* 适用于自由度df=1的2×2列联表

🎯 解题步骤口诀

  1. 画列联表，算边缘合计
  2. 计算理论频数Eij
  3. 代入卡方公式计算χ²
  4. 确定自由度和临界值
  5. 比较χ²与临界值，作出判断
