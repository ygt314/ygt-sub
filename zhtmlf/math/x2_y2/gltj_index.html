📚 核心公式速查

古典概型：P(A) = 事件A包含的基本事件数 / 基本事件总数

二项分布：P(X=k) = C(n,k)·p^k·(1-p)^(n-k)

超几何分布：P(X=k) = C(M,k)·C(N-M,n-k) / C(N,n)

期望：E(X) = Σx_i·p_i

方差：D(X) = E(X²) - [E(X)]²
